## Overview
A marketing landing page that Master Homes used to advertise an Ellington Properties project on Dubai Islands. It
shares its structure with [fairmont-downtown](../fairmont-downtown/) and [ramhan](../ramhan/) and forwards leads to the
sales team by e-mail (see [smtp-service](../smtp-service/)).

## Key Features
- Project showcase section with location, key selling points (sea-facing apartments, amenities) and image carousel
- Highlights, Overview, Price plan and Project gallery sections
- Travel-time / nearby landmarks block
- Register-interest modal with a lead form and international phone input
- Quick contact buttons (phone, WhatsApp, Telegram)
- Static build served by Nginx in Docker
