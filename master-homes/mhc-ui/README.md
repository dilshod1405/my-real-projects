## Overview
A compact Next.js site that presents the contracting arm of the Master Homes group: construction, decoration and
technical maintenance services. It complements the real-estate website [mhp-ui](../mhp-ui/) and is built as one
long, animated landing page.

## Key Features
- Hero slider with autoplay project photos (Swiper)
- Services grid covering building contracting, decoration (including 3D-printed decor), MEP / HVAC maintenance, plumbing, carpentry, tiling, plaster and more
- Developer / partner logo carousel
- Animated request modal with a validated contact form (react-hook-form, Framer Motion)
- Quick contact actions: click-to-call, WhatsApp, Telegram, copy-to-clipboard, social links
- Responsive mobile menu
