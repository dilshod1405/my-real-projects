## Overview
Public product site for Edge24. It presents the three product layers — Cloud (control plane), Agent (data plane)
and Hardware (Edge24 box with UPS) — and drives visitors to the [cloud console](../edge24-cloud-ui/).

## Key Features
- Single-page landing with sections: Hero, Product, Architecture, Hardware, Pricing, Docs, FAQ, call-to-action
- Animated network-grid hero and scroll-reveal / scroll-progress effects
- Hardware visuals for the Edge24 box and UPS module
- SEO: structured data (JSON-LD), sitemap, robots, generated Open Graph image
- Light/dark theme toggle, responsive navigation with mobile sheet menu
